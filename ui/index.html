Send to Ledger: a Chrome and Firefox extension that sends files from any website straight into this inbox (or makes them a statement, a bill or a receipt right away), without saving them to your computer. Right-click a download link and choose Send to Ledger…, or drop a file on its toolbar button.
  1. Chrome, Edge, Brave: unzip it, open chrome://extensions, turn on Developer mode, choose Load unpacked and pick the unzipped folder.
  2. Firefox: open about:debugging#/runtime/this-firefox → Load Temporary Add-on… → pick manifest.json in the unzipped folder (until Firefox restarts; to keep it, sign it for yourself on addons.mozilla.org, see the README).
  3. Click the extension's toolbar button. It already knows this Ledger (): press Allow and continue and accept the browser's question. That's all.
  4. Updating it later: unzip the new download over the same folder and press Reload on the extensions page. Loading it from a new folder makes the browser treat it as a new extension that has to be allowed again.

Scanner plugged into a computer by USB?

A web page can't reach a USB scanner, so a small program on the computer it's plugged into (your PC, or the Ledger server itself) shares it with Ledger as a network scanner. Then it scans from here on any device, phones included.

Windows: ledger-scan-bridge.ps1 Mac and Linux: ledger-scan-bridge.py
  1. Windows (uses Windows' own scanner support, nothing to install): the first time, right-click the Start button → Terminal (Admin), go to the folder you saved it in (e.g. cd Downloads) and run powershell -ExecutionPolicy Bypass -File .\ledger-scan-bridge.ps1. It reserves its port and opens it in the firewall for your home network. Next times a normal window works.
  2. Mac and Linux (uses SANE): install it once (Mac: brew install sane-backends; Debian/Ubuntu: sudo apt install sane-utils), then run python3 ledger-scan-bridge.py.
  3. It prints an address such as http://192.168.1.25:8090/eSCL. An admin enters it here (Change scanner → the address → Use this address). On the Ledger server itself, use http://127.0.0.1:8090/eSCL.
  4. Leave the bridge running while you scan; start it again after a restart (or put it in the computer's startup items).

Options

Set in Ledger under Settings → Auto sort: review threshold and batch size on its Sorting tab, the accounts payable account on Bills, the largest file and how long sent entries are kept on Inbox, reading email on Email, the network scanner on Scanner.

Files

Every file this module handles (statements, bills, receipts, saved emails, scans) is kept in Ledger's Documents, never by the module itself. What was read out of a file is kept with it there, so it is read once; Ledger's tags on a file say whether it is posted, paid or overdue.

Files from other modules

Statements, bills and receipts other Ledger modules handed to Auto sort. Nothing is posted until you approve it.
