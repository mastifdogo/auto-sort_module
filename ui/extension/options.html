Send to Ledger

The address you open Ledger at in this browser, e.g. http://ledger.local:8080 or https://ledger.example.com. The browser asks once to let the extension reach that address, and only that address.

With more than one organization in Ledger. "Where Ledger is now" follows the organization you last chose in Ledger. Another one is used even while Ledger is in a different one: Ledger is switched to it for the few seconds of sending and back again (pages of Ledger open meanwhile are in that organization for those seconds). The window that opens when you send a file can choose another organization for that file.

How it works

  • Right-click a download link on your bank's or a supplier's site and choose Send to Ledger…. The file is downloaded with that site's login and goes straight to Ledger, without being saved to your computer.
  • Or click the toolbar button and drop a file you already have.
  • By default files land in the inbox of the Auto sort module in Ledger (which the Import module is part of since Auto sort 0.17.0), where you make them a statement, a bill or a receipt, send them on, archive or delete them. Statements (CSV, OFX, QFX, QBO), bills and receipts (PDF, photos, EML) can also be made that straight from here. Every file is kept in Ledger's Documents. CSV files can go to Ledger's own journal import.
  • It uses your Ledger login in this browser; log in to Ledger as usual. The extension stores only the address above, never a password. Requests to Ledger are made from a Ledger tab (a hidden one is opened and closed if none is open), so Ledger's protections stay on.
